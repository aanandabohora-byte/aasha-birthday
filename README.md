# Birthday Wish Journey

A mobile-friendly React + Tailwind + Framer Motion birthday experience.

## Run locally

1. Install Node.js (18+ recommended).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. For production: `npm run build`.

Background melody is synthesized in-browser (no audio asset needed). Tap a button once to start browser audio.
